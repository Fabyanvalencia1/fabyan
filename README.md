# 🚀 OASIS CREW - Calculadora de Horas Proyectadas

Sistema completo de gestión y proyección de horas de trabajo para equipos, con funcionalidades avanzadas de administración, exportación y análisis.

![Version](https://img.shields.io/badge/version-2.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)

## ✨ Características Principales

### 📊 Gestión de Empleados
- ✅ Agregar/eliminar empleados individualmente
- ✅ Base de datos de empleados comunes reutilizables
- ✅ Organización por departamentos (Plantación, Puller, Growing, Mantenimiento)
- ✅ Códigos personalizados para empleados
- ✅ Búsqueda y filtrado avanzado

### ⏰ Cálculo de Horas
- ✅ Registro de horarios de entrada y salida por día
- ✅ Cálculo automático de horas trabajadas
- ✅ Descansos configurables
- ✅ Detección de turnos nocturnos
- ✅ Alertas de exceso de límite de horas
- ✅ Códigos de día personalizables

### 🔄 Herramientas de Productividad
- ✅ **Copiar/pegar horarios** entre empleados
- ✅ **Alineación masiva** de horarios
- ✅ **Deshacer/Rehacer** cambios (Ctrl+Z / Ctrl+Y)
- ✅ **Auto-guardado** cada 30 segundos
- ✅ **Atajos de teclado** para acciones rápidas
- ✅ **Modo oscuro** con persistencia

### 📤 Exportación y Reportes
- ✅ **Exportar a Excel** (.xls)
- ✅ **Exportar a CSV**
- ✅ **Generar PDF** con tablas formateadas
- ✅ **Imprimir** directamente desde el navegador
- ✅ **Plantillas** guardables y reutilizables

### 📈 Análisis y Estadísticas
- ✅ Resumen general con totales y promedios
- ✅ Estadísticas por departamento
- ✅ Gráficos visuales (barras y donut)
- ✅ Identificación de empleados que exceden límites
- ✅ Cálculo de horas totales y promedio

## ⌨️ Atajos de Teclado

| Atajo | Acción |
|-------|--------|
| `Ctrl + S` | Guardar datos |
| `Ctrl + Z` | Deshacer |
| `Ctrl + Y` | Rehacer |
| `Ctrl + N` | Agregar empleado |
| `Ctrl + P` | Imprimir |
| `Ctrl + E` | Exportar a Excel |
| `Ctrl + M` | Administrar empleados |
| `Ctrl + D` | Modo oscuro |

## 🚀 Uso

1. Abre `index.html` en tu navegador
2. Configura límite de horas y tiempo de descanso
3. Agrega empleados o carga desde la lista común
4. Ingresa horarios para cada día
5. Calcula totales y genera reportes

## 🛠️ Tecnologías

- HTML5, CSS3, JavaScript ES6+
- Chart.js para gráficos
- jsPDF para PDFs
- LocalStorage para persistencia
